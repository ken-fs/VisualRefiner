# Homepage Surface Brief

## Scope and mode

Homepage. Persuade first-time search visitors, then let them operate a real image converter inside the first viewport.

## Audience, job and action

An English-speaking visitor has an image or video file that needs a specific result. They should understand the local-processing promise, either convert an image immediately or choose a more specific tool, then download the result without an account.

## Proof and constraints

The working browser-local converter is the proof. The `file → browser → download` diagram explains the mechanism. Do not fabricate customer counts, speed claims, testimonials or security certifications. No AI, payment, server upload, YouTube download or watermark-focused content belongs in the first release.

## Direction and memorable moment

The visual world is a precision inspection table. A celadon-grey work surface, graphite type, calibration orange actions, ruler ticks, registration marks and an inspection lens frame the tools. The memorable moment is a real file entering the large inspection field while the surrounding interface stays visibly local and task-focused.
